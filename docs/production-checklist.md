# 实盘上线前检查清单

## 目标

该文档用于在历史回放和 CTP 测试环境验证完成后，再进入小资金真实交易前执行。

## 账户环境

- 确认期货公司 CTP 前置地址。
- 确认 BrokerID、账户权限和交易所权限。
- 确认保证金率、手续费、平今规则与配置一致。
- 确认账户没有其他程序同时交易。

## 策略检查

- 使用最新交易日数据重新回放。
- 检查价差计算是否连续。
- 检查合约换月规则。
- 检查临近到期禁止开仓逻辑。

## 风险检查

- 测试断线后的停机保护。
- 测试持仓不一致后的禁止交易。
- 测试双腿成交失败后的修复流程。
- 测试每日亏损限制。

## 实盘流程

1. 历史数据回放。
2. CTP 测试环境运行。
3. 极小资金验证。
4. 连续多个交易日观察。
5. 再逐步提高资金规模。

## 原则

系统默认优先保护本金，不因为追求交易机会绕过风险检查。
