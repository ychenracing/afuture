# 生产上线检查表

## 账户与权限

- [ ] 使用期货公司测试柜台完成登录、行情、下单、撤单和成交验证。
- [ ] 确认 BrokerID、AppID/AuthCode 和目标交易所/品种权限。
- [ ] 确认账户不会被其他自动程序同时操作同一批合约。
- [ ] 确认期货公司当前保证金、手续费和平今费。

## 合约与策略

- [ ] `auto.products` 只包含自己愿意交易且已开通权限的品种，不直接无差别扫描全市场。
- [ ] `auto.session_windows` 与白名单内所有品种共同可交易时段一致；默认日盘最简单。
- [ ] 自动发现能在测试柜台看到 CTP 合约目录、订阅候选并生成/退役动态组合。
- [ ] 已有动态组合在重启后能从状态文件恢复，并在持仓对账前重新获得管理权。
- [ ] `multiplier`、`price_tick` 与 CTP 合约信息一致。
- [ ] 本地保证金和手续费不低于 CTP 实时查询值。
- [ ] `expiry_near`、`expiry_far` 是真实最后交易日，不是示例日期。
- [ ] `session_windows` 与目标品种当前日盘/夜盘一致。
- [ ] 近远月流动性和 Open Interest 足够支撑计划手数。

## 研究证据

- [ ] 多年份/多市场状态 Walk-forward 已完成。
- [ ] OOS 正收益比例达到自定门槛。
- [ ] 最大 OOS 回撤在风险预算内。
- [ ] 1.5x、2x 成本压力没有出现不可接受崩塌。
- [ ] 参数位于稳定区域，不是孤立历史最高点。
- [ ] 删除单一时间区间或更换月份后策略没有明显失效。

## 执行与异常

- [ ] 双腿第二腿拒单时第一腿撤单/减仓回滚已在测试柜台验证。
- [ ] 部分成交和裸腿能进入 `REDUCE_ONLY`。
- [ ] 封板或流动性不足时不会继续增加风险。
- [ ] CTP 断线、快照陈旧和未知订单会触发停机。
- [ ] 持仓对账失败不会覆盖本地期望状态。
- [ ] Kill Switch 重启后仍保持。

## 运行与告警

- [ ] `runtime/` 所在磁盘可靠且有备份策略。
- [ ] `audit.jsonl`、`alerts.jsonl` 和日志可以正常写入。
- [ ] Webhook（如启用）在真实网络环境测试通过。
- [ ] 明确夜盘无人值守时谁负责处理 CRITICAL 告警。

## 资金递增

- [ ] 第一阶段只用测试柜台。
- [ ] 第二阶段只用极小真实仓位。
- [ ] 连续多个交易日验证持仓、手续费、滑点和交易日后再扩大。
- [ ] 扩大资金时先提高风险预算验证，不直接把保证金使用率推到上限。
