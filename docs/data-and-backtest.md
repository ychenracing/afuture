# 数据与回放

## CSV 格式

历史 Tick 文件必须包含：

```text
timestamp,symbol,exchange,bid_price,ask_price,last_price,bid_volume,ask_volume,trading_day
```

要求：

- `timestamp` 必须是带时区的 ISO 8601 时间；
- 买一、卖一价格必须大于 0，且卖一不低于买一；
- `trading_day` 应使用期货交易日，而不是简单按自然日生成；
- 两条腿需要足够同步，否则陈旧行情过滤会拒绝把它们输入策略。

可选字段 `limit_up`、`limit_down` 可提供涨跌停价；CTP 实盘会自动读取，执行器会把主动限价限制在涨跌停范围内。

## 回放假设

模拟撮合使用一档盘口。主动买单以卖一为基准，主动卖单以买一为基准，再叠加配置的滑点。成交量不能超过该档可用数量；FAK/FOK 按对应语义处理。

手续费同时支持按手和按成交额配置，并区分开仓、普通平仓和平今。保证金按静态配置估算。

这些假设仍然不能完整复刻真实排队、交易所撮合延迟、期货公司风控和极端行情流动性，因此历史回放只能作为策略筛选证据，不能视为实盘收益保证。

## 报告指标

`report.json` 包含：

- 初始资金、最终权益；
- 总收益率；
- 年化收益率；
- 最大回撤；
- 日频夏普；
- 回放交易日数；
- 成交笔数；
- 最终账户和持仓。

样本很短时年化指标会被严重放大，应优先看总收益、最大回撤、成交分布和多市场阶段稳定性。
